# Belt and Tread Defect Detection

A technical archive of an industrial belt and tread defect detection project based on structured-light height maps, geometric measurement, and transform-domain structural patterns.

## Overview

This repository documents a real industrial inspection project for belt and tread defect detection on a tire building drum.  
The focus is not only on defect recognition, but also on geometric representation, real-time measurement, and transformed-domain structural patterns for joint-state analysis.
